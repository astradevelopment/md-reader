MD Reader

Читалка Markdown для Mac. Не редактор — открывает .md и не мешает читать.

Скачать для Mac

macOS 15 или новее

  • Оглавление сбоку и отметка, где вы читаете
  • Вкладки в одном окне, у каждой своя позиция
  • Поиск по документу с подсветкой абзаца
  • Обновляется само
Первый запуск macOS заблокирует — что делать

Приложение подписано ad-hoc, без сертификата Apple. Перетащите его в «Программы» и один раз выполните в Терминале:

xattr -dr com.apple.quarantine "/Applications/MD Reader.app"

Дальше обновления ставятся сами — повторять не нужно.
