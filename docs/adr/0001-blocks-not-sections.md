# 0001. Отрисовка по блокам, а не по секциям

Дата: 18.08.2026

## Контекст

Читалка рисовала одну вью на секцию — всё от заголовка до следующего заголовка.
При переходе к найденному совпадению подсвечивалась вся секция: на спецификациях
это пол-экрана синевы, по которой невозможно понять, где именно нашлось слово.

Подсветить само слово нельзя: MarkdownUI рисует текст сам и хука внутрь не даёт.
Достижимая точность — абзац.

## Решение

Резать каждую секцию на блоки (`MarkdownBlocks.split`) и рисовать по вью на блок.
Поиск адресует блоки, подсветка размером с абзац.

Правила резки нетривиальны и вынесены в чистую функцию с тестами: пустая строка
заканчивает блок, но не внутри ограждения кода; два списочных блока, разделённых
пустой строкой, склеиваются обратно, иначе второй список начнёт нумерацию заново.

## Последствия

Хорошее: подсветка попадания размером с абзац; ленивая отрисовка стала возможна
(84 мс против 800 на открытие).

Плата: **выделение текста не переходит между блоками** — в SwiftUI выделение не
пересекает границу вью. Раньше выделялось в пределах секции, теперь в пределах
абзаца. Обходной путь — ⇧⌘C «Скопировать весь документ». Вопрос открыт.

Отдельно пришлось воспроизвести отступы, которые MarkdownUI ставил между блоками
сам: теперь они заданы явно по значениям темы. Проверено замером — см.
`docs/testing.md`.

## Альтернативы

**Оставить секции.** Выделение шире, но подсветка бесполезна на длинных разделах.

**Рисовать в один `NSTextView`.** Настоящее свободное выделение по всему
документу, но это отказ от MarkdownUI и переписывание читалки целиком.
