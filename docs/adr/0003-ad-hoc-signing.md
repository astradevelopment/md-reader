# 0003. Подпись ad-hoc и что из этого следует

Дата: 18.08.2026

## Контекст

Apple Developer ID стоит 99 долларов в год. Без него приложение подписывается
ad-hoc: подпись есть (на Apple Silicon без неё вообще не запустится), но нет ни
идентификатора команды, ни нотаризации.

Проверить можно так:

```
spctl -a -vvv "MD Reader.app"   → rejected
codesign -dvv "MD Reader.app"   → Signature=adhoc, TeamIdentifier=not set
```

## Решение

Живём с ad-hoc и снимаем карантин руками при первой установке.

## Последствия

**Первый запуск на чужом Mac блокируется.** Лечится один раз:

```bash
xattr -dr com.apple.quarantine "/Applications/MD Reader.app"
```

На macOS 15 и новее правый клик → «Открыть» блокировку больше не обходит, только
эта команда или «Всё равно открыть» в настройках безопасности (кнопка появляется
не всегда).

**Обновления этой проблемы не имеют.** Образ, скачанный самим приложением через
`URLSession`, карантином не помечается — метку ставит браузер, а не система. Плюс
установщик на всякий случай снимает её со промежуточной копии. То есть танец с
Gatekeeper нужен ровно один раз, при первой установке.

Что проверялось прежде, чем свалить всё на Gatekeeper: минимальная система
бандла (15.0), архитектура (arm64), связанные библиотеки (все системные) и
символы macOS 26 — все десять слабо слинкованы, то есть на 15.x просто не
подгружаются и запуску не мешают.

## Альтернативы

**Купить Developer ID и нотаризовать.** Единственный способ, чтобы открывалось
без команды. Если приложение уйдёт дальше пары человек — стоит вернуться.
